### Physical Therapy License Examination Review & Interactive Mock Exam (Subject 03)

ระบบคลังข้อสอบและคู่มือติวสอบใบประกอบวิชาชีพกายภาพบำบัด **วิชา 03 (กายภาพบำบัดในโรค ภาวะ และกลุ่มอาการ)** จำนวน **500 ข้อเต็ม** (5 ชุด ชุดละ 100 ข้อ) พร้อมระบบทำข้อสอบจำลองเสมือนจริงแบบโต้ตอบ (Interactive Web Exam Simulator) บนเว็บเบราว์เซอร์

### คุณสมบัติของระบบทำข้อสอบ (Interactive Web Dashboard):
- ⏱️ **ระบบจับเวลาสอบจริง**: 120 นาทีต่อชุดข้อสอบ หรือโหมดฝึกฝนตามอัธยาศัย
- ✅ **ตรวจคำตอบทันที (Instant Grading)**: ไฮไลต์สีเขียว (ถูก) / สีแดง (ผิด) พร้อมคำนวณคะแนนรวมและเปอร์เซ็นต์แบบเรียลไทม์
- 📖 **เฉลยละเอียดระดับอาจารย์แพทย์/อาจารย์กายภาพบำบัด**:
  - Medical Rationale (กลไกพยาธิสรีรวิทยาและเหตุผลทางการแพทย์)
  - Distractor Analysis (วิเคราะห์เจาะลึกว่าเหตุใดตัวเลือกอื่นถึงไม่ถูกต้อง)
  - High-Yield Clinical Pearl (สูตรจำและจุดสังเกตสำคัญในห้องสอบ)
- 🔍 **ระบบค้นหาคำสำคัญ (Search Filter)**: ค้นหาโจทย์ตามชื่อโรค เช่น `Pusher`, `Pavlik`, `Gowers`, `ASIA`, `COPD`, `Lachman`
- 📑 **ตารางสูตรลัดและค่ามาตรฐาน (Cheat Sheet)**: สรุปค่า ABG, METs, อุปกรณ์ช่วยเดิน, พัฒนาการเด็ก, และระดับการบาดเจ็บไขสันหลัง

## 🛠️ วิธีเปิดใช้งานบนเครื่องตนเอง (Offline Usage)

1. ดาวน์โหลดหรือ `git clone` โปรเจกต์นี้ลงเครื่อง:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วย Google Chrome, Microsoft Edge, หรือ Safari สามารถใช้งานได้ทันทีโดยไม่ต้องต่ออินเทอร์เน็ต

## 🚀 วิธีตั้งค่า GitHub Pages สำหรับเผยแพร่ออนไลน์

1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. เลือกเมนู **Pages** (แถบด้านซ้าย)
3. ในส่วน **Build and deployment > Branch**:
   - เลือก Branch: `main`
   - เลือก Folder: `/ (root)`
4. กด **Save**
5. รอประมาณ 1-2 นาที GitHub จะแสดงลิงก์เว็บไซต์ เช่น `https://<username>.github.io/<repo-name>/` พร้อมเข้าใช้งานได้จากทุกที่ทั่วโลก!
